# Citation

If you use cyCombinePy, please cite this software and the original cyCombine
paper. The repository includes machine-readable citation metadata in
`CITATION.cff`.

## cyCombinePy

Use the metadata from `CITATION.cff` for the software citation, including the
version used in your analysis.

## Original cyCombine method

Pedersen, C.B., Dam, S.H., Barnkob, M.B., et al. cyCombine allows for robust
integration of single-cell cytometry datasets within and across technologies.
Nature Communications 13, 1698 (2022).
https://doi.org/10.1038/s41467-022-29383-5
